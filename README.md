# Третье ДЗ по ипр, выполнено на 6 баллов

Веб-приложение со счётчиком в Docker. Для запуска можно использовать Docker Compose. 
Счётчик хранится в SQLite и сохраняется в Docker volume.

## Структура проекта
    app/ -- код приложения
    Dockerfile -- сборка docker-образа
    .dockerignore -- исключения для контексста сборки
    compose.yaml -- конфигурация Docker Compose
    .gitignore -- исключает локальный .env, чтобы он не пушился
    .env.example -- пример переменных окружения

## Настройка своих переменных окружения
Создайте локальный файл .env на основе примера:

    cp .env.example .env
В .env задайте:

    GREETING=...     <приветствие приложения>
    APP_PORT=...     <порт компьютера, на котором доступно приложение>

Внутри контейнера приложение использует порт 8000.

## Запуск
Сборка образа и запуск приложения:

    docker compose up -d --build
Проверка состояния:

    docker compose ps
Проверка приложения:

    curl http://localhost:8080/
Увеличение счётчика:

    curl -X POST http://localhost:8080/increment
Просмотр логов:

    docker compose logs
Остановка:

    docker compose down

## Хранение счётчика
Для хранения SQLite используется Docker volume counter_data, подключённый к /data внутри контейнера.

Файл базы данных находится по пути /data/counter.db.
